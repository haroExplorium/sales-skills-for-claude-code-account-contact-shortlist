<h1 align="center">Sales Skills for Claude Code: Account Contact Shortlist</h1>

<p align="center">
  <strong>Build a ranked shortlist of contacts at a target company for prospecting, deal acceleration, or renewal/expansion plays. Provide a company name or domain and optionally a use case or seniority focus.</strong>
</p>

---

## Overview

Drop this skill into Claude Code and your AI agent gains the ability to pull the right people at a target account and rank them for outreach, with a use-case lens (new business, active deal, renewal) and a reachability check.

This skill is part of a 14-skill series covering the full B2B sales workflow, powered by the [Explorium AgentSource API](https://explorium.ai) — 350M+ people, 80M+ companies, real-time firmographics, technographics, funding signals, and verified contact data.

## Repository structure

```
.
```

## Installation

### Claude Code

```bash
/plugin marketplace add https://github.com/explorium-ai/Agent-skills
```

### Cursor / Windsurf / any agent that reads Markdown

Point your agent at `SKILL.md` for the full skill instructions.
